## Korean keywords

Added 2026-10-24 on owner request, because most conversations are in Korean. They are used for classification together with the English keywords above. Korean terms are matched as substrings, since particles attach to words (`재고를`, `회계는`). `ERP` and `SQL 인젝션` are included because Korean text uses them as written. A term written as `term (N+)` only counts when it occurs at least N times in a note.

Revised the same day after the first review run: generic words that caused false matches were removed (`영업`, `판매`, `백엔드`, `시간대`, `윈도우`, `이관`) or made more specific (`생산` → `생산관리`, `구매` → `구매관리`·`발주`, `에이전트` → `AI 에이전트`·`코딩 에이전트`), and `보안` now needs 3 occurrences.

Owner decision 2026-10-24: English `production` means the production (operations) environment, so it moved from `ERP-Business-Domains` to `Dev-Environment-and-Git` (with Korean `운영환경`); manufacturing in ERP is matched with `manufacturing` / `manufacture`.

## Design notes

- **Technical topics only.** Founder-level themes from the local briefing are not technical categories and are left out: the public platform, Swedenborg / philosophy content, and community features. They could become a separate non-technical tree later.
- **Granularity.** Topic 12 is broad. If many ERP notes accumulate, split it by module (`ERP-MM`, `ERP-SD`, `ERP-FI`, `ERP-PP`).
- **Multiple topics per note are expected.** A Claude Code session about QuroHarness SQL analysis would get `Legacy-System-Analysis` + `Oracle-to-PostgreSQL-Migration` + `Claude-Code-and-AI-Assisted-Dev`.
- **Raw notes stay untouched.** Topic assignment should live in `02_Knowledge` (index notes linking to `01_Original`), in line with OPEN_QUESTIONS Q6.
